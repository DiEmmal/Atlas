Atlas endpoint reference

A compact guide to the available routes for accounts, posts, activity and user profiles.

Authentication

Access and account validation
Method Endpoint Description Access
POST /api/auth/register Create an account with name, email and password. Public
POST /api/auth/login Sign in and receive a JWT. Public
GET /api/auth/validate-email/:token Validate an account email address. Public

Posts and activity

Content, likes and comments
Method Endpoint Description Access
GET /api/posts Browse posts with optional pagination. Public
POST /api/posts Create a post with an optional image field. JWT
POST /api/posts/:postID/likes Add or remove the authenticated user's like. JWT
POST /api/posts/:postID/comments Add a comment to a post. JWT
GET /api/posts/image/:fileName Retrieve an image stored in uploads/posts. Public

Users and profiles

Directory and profile images
Method Endpoint Description Access
GET /api/users List registered users. Public
GET /api/users/:userID Get one user profile. Public
PUT /api/users/:userID Update profile data or upload its image. JWT
GET /api/users/:userID/image Retrieve the profile image by user ID. Public
ATLAS Protected routes use Authorization: Bearer <token> | Image uploads are limited to 5 MB.
